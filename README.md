# Claude loader animations

Looping GIFs shown by a private Slack bot while it works. Drawn in code (Pillow), no external assets.

- `montages/` — Spark's multiverse: 10-second montages, three universes each (knight, mage, space blade, masked
  hero, voxel world, fantasy quest, pirate, samurai, cyber city, far west, deep sea, sky hero), a costume per universe.
- `scenes/`, `claude-*.gif` — earlier versions.
