# Claude loader animations

Looping GIFs shown by a private Slack bot while it works. Drawn in code (Pillow), no external assets.

- `montages/` — Spark's multiverse: 23 montages of ~19 s, three universes each, 40 universes in all (knight, mage, space blade, voxel world, fantasy quest, pirate, samurai, dinosaurs, Egypt, vikings, fairy forest, 8-bit arcade, falling blocks, snake, retro web, 404 desert, cookie factory…), a costume per universe.
- `scenes/`, `claude-*.gif` — earlier versions.
