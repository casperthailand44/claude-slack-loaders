# Claude loader animations

Looping GIFs shown by a private Slack bot while it works. Drawn in code (Pillow), no external assets.

- `scenes/` — Spark the mascot travelling the web: home, the portal, one world per kind of site (library, forum town,
  code factory, cinema, bazaar, city, museum, space, sea), thinking, writing, and rare episodes.
- `claude-*.gif` — the first, simpler loaders.
